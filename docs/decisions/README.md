# Decisions

Current state only; history is in git. To change a decision, edit its file and its line here in the same commit. Decisions keep one numbering across the trains' repositories; the full index is aeolus-fleet's [docs/decisions/README.md](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/decisions/README.md).

- [0036](0036-networking-plugin-package.md) **Networking plugin package.** The first networking plugin, optional, its own package and process beside squadrons, a ship of each fleet (fleet:read, fleet:network), connected and switched as squadrons; its own small database holds per fleet the connection, the switch and the network argo edits (the rules and what it declares, keep-latest after 300 seconds until argo sets it), argo's only; supplies the whole list (argo's plus the declared rules, [0037](https://github.com/ThomasHendrickx/aeolus-fleet/blob/main/docs/decisions/0037-declared-network-rules.md)) on every change, on reconnect and on NetworkRulesDeclared, one supply of a fleet at a time, retrying what the fleet refused; off unregisters; a delete unregisters first and is refused while the fleet does not answer; its ship acknowledges every delivery and acts on none.
