# Aeolus networking plugin

`@aeolus-fleet/networking-plugin` holds the rules for which ships of an [Aeolus](https://github.com/ThomasHendrickx/aeolus-fleet) fleet may message which, and gives them to the fleet, which enforces them on every send. It is optional: a ship of each fleet it serves, beside core, reaching the fleet only through its public API. How to run it and its API: [packages/networking-plugin/README.md](packages/networking-plugin/README.md). For the product, see [aeolus-fleet](https://github.com/ThomasHendrickx/aeolus-fleet).
